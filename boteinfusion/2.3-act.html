Tool Correct Platform Why
🌐 annotate.net Web Browser annotate.net is web-based — it writes on websites and browser content only. It doesn't work inside desktop apps like PowerPoint or Word.
📊 ClassPoint.io PowerPoint ClassPoint is a PowerPoint extension adding advanced pens, highlighters, shapes and notes directly inside PowerPoint presentations.
✏️ Word Draw Tools Microsoft Word Word's Draw tab enables pens, pencils and highlighters for annotating documents live. It must be added via "Customize the Ribbon" as it's hidden by default.
📄 Edge Built-in Annotator PDF (in Edge) Edge has built-in PDF annotation tools in its toolbar. Jakob recommended keeping the browser in normal view — not F11 — so these tools stay accessible.
🖼️ Full-Screen Editable Slides Google Slides / PowerPoint By hiding panels and pressing F11 while staying in editor view (not slideshow mode), teachers get a full-screen live workspace to type, add images and annotate in real time.
